# Argus × Secretariat: x402 Integration Roadmap

**Дата:** 2026-09-18
**Статус:** Architecture decisions fixed. Implementation not started.
**Контекст:** Разбор после месяца разработки Model V0 (Argus) и Stage A/B (Secretariat).
Внешняя рецензия пройдена (2 независимых рецензента, слепой протокол).
Эксперимент Qwen (локальное подключение проектов) — отдельная задача, учтён в §7.

---

## 0. Executive Summary

**Что решили:**
- Secretariat должен стать **x402-совместимым Resource Server** (входящий edge).
- Argus должен стать **минимальным x402-совместимым test client**.

**Что НЕ решили:** конкретную реализацию wire-деталей. Этим займёмся
после закрытия блокеров (§7) и открытых вопросов (§8).

**Порядок работы:** последовательный.
Secretariat x402 edge → **референсный клиент** (curl + скрипт-подписант,
не Argus) → зелёный ручной e2e → Argus против **проверенного** контракта.

**Принцип:** эталон x402 V2 задаёт wire. Одна сторона его реализует,
вторая — соответствует. Угадывать wire двумя сторонами одновременно —
interop-фейл без возможности установить виновника.
