## BACKLOG 7.4 — Observation emission for non-testSubject ARGUS-owned participants

**Статус:** known gap, не блокирует фазы 8/9/11.

**Проблема:** Model V0 сейчас поддерживает observation-источники только для testSubject (через exchange.metadata.observations) и engine (через action_<type> events). Участники с ownership=ARGUS, не являющиеся ни actor'ом действия, ни testSubject — например, seller-1 в S7 — физически не имеют механизма эмитить observations (delivery_sent и подобное).

**Где блокирует:** S7 (Lost Delivery) не может стать реальным без решения. S2/S4 частично блокированы тем же (seller-1 там тоже должен реагировать, не только принимать fault).

**Не решать до:** пока не придёт очередь делать S2/S4/S7 реальными (сейчас все — INCONCLUSIVE by design, Variant A).

**Затронутые файлы (предположительно, не проверено):**
- ScenarioEngine — нужен новый путь эмиссии, не performAction (тот привязан к actor→testSubject flow)
- Возможно FaultInjector, раз seller-1 fault handlers (hang, delayed_response, lost_delivery) — вероятный источник этих observations

**Источник:** обсуждение в ходе Фазы 7.3 (source observation = testSubject vs actor).

## Известные ограничения Model V0

1. **Target Opaque:** AgentController/AgentTargetPort не знают конкретных target'ов (payment, settlement, escrow). Любое упоминание 'secretariat', 'buyer', 'seller' как hardcoded строк — нарушение принципа.
2. **Evidence Collection:** Только ScenarioEngine.collect() эмитит evidence. AgentController — транспорт.
3. **Observation Sources:** Только testSubject и 'engine'. Другие участники (ARGUS-owned, не testSubject) не эмитят observations до 7.4.
4. **Fault Injection:** Работает только через FaultInjector.apply(). MockTargetAdapter не знает словарь fault'ов.
